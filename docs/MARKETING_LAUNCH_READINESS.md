## 2. 이미 준비된 것 (2026-10-26 배포)

- 안쪽 화면까지 **밝고 맑은 앱**으로 바뀜 (정착·교회·도움·탐방·취업·교육·생활비)
- **나눔은 1인칭 고백**: 1면 "나도 이 마음에 함께해요", 앱 홈 "곧 이 도시로 오는 분이 떠오르나요? · 함께 나누기"
- **공유 글 9종**을 환대의 말투로 다시 씀(재촉어·이모지 없음)
- **링크 미리보기 문구**: "HebronGuide ○○ — 처음 오신 분을 맞이합니다" (사실이 아닌 "16.5만이 검증" 문구 삭제)
- **헤브론 우물가**: 원문을 확인한 사기 경보·무료 행사·공식 기관 (시애틀)
- **의견 상자**: 메일 앱 대신 기록이 남는 방식(검토 대기 저장 + 관리자 메일)
- **교회 탭**: 들어오면 바로 목록, 전화번호는 "새가족 신청하기" 안에서만

## 3. 팬십 — 시키지 않아도 나누게 되는 구조

소속감은 부탁해서 생기지 않는다. **자랑스럽고 유익할 때** 사람이 스스로 이름을 건다(목사님, 2026-10-26).

MARKETING_STRATEGY.md 3장의 두 번째 여정이 팬십의 길이다.

```
고립된 이민자 → 뿌리내린 나그네 → 다음 사람의 안내자
```

팬은 **"다음 사람의 안내자"가 되는 순간** 생긴다. 그래서 장치는 모두 "안내자가 될 기회"여야 한다.

| 장치 | 상태 | 하는 일 |
|---|---|---|
| 1인칭 나눔 | 완료 | "나도 이 마음에 함께합니다"를 자기 목소리로 보낸다 |
| 정보 고치기 | 완료 | 의견 상자로 "예배 시간이 바뀌었어요"를 알려 주면, 그 사람이 지도를 함께 그린 사람이 된다 |
| 이야기 올리기 | 있음(`story-submit.html`) | 정착 이야기가 다음 사람의 안내가 된다 |
| 식탁 초대 | 시애틀 시범(`gathering.html`) | "이번 주 식탁의 자리" — 지표와 바로 이어진다 |
| 고쳐진 것을 알려 주기 | **할 일** | 의견이 반영되면 "고쳐졌어요"를 우물가에 짧게 적는다. 내 말이 지도에 남는 경험이 소속감을 만든다 |

**하지 않는 것**: 포인트·순위·추천 보상·"친구 3명 초대하면". 보상이 붙는 순간 나눔이 거래가 된다(WORDS_OPEN_DOORS).

## 4. SNS — 8개 채널

### 계정은 목사님이 만드셔야 한다

계정 개설에는 본인 인증과 전화번호가 필요하고, Claude가 대신 만들 수 없다. 만드신 뒤 예약 게시 도구(예: Postiz)에 연결해 주시면 **Claude가 초안을 쓰고 → 목사님이 승인하고 → 예약 게시**하는 흐름까지는 자동으로 돌릴 수 있다.

### 순서 — 한 번에 8개를 열지 않는다

채널이 늘면 관리가 얇아지고, 얇은 채널은 오히려 신뢰를 깎는다. 정본 4장 "뾰족함"을 따른다.

| 단계 | 채널 | 이유 |
|---|---|---|
| 1 (지금) | 카카오톡 채널 (이미 있음 `pf.kakao.com/_dxdxlbX`) | 한인이 실제로 묻고 답하는 곳 |
| 1 | 인스타그램 | 도시 장면·식탁 사진이 자연스럽게 퍼지는 곳 |
| 1 | 유튜브 | MARKETING_STRATEGY.md 8장의 주 채널. 쌓이고 AI가 학습한다(정본 2장) |
| 2 (첫 달 뒤) | 페이스북 페이지 · 네이버 밴드 | 40대 이상·교회 공동체 |
| 3 (석 달 뒤) | 스레드 · X · 링크드인 | 1면 공유 아이콘과 같은 묶음. 필요가 보일 때 연다 |

### 지키는 것

- **일요일에는 홍보 게시를 하지 않는다** (운영 원칙 1)
- **8곳에 같은 글을 동시에 뿌리지 않는다.** 플랫폼이 스팸으로 묶을 수 있고, 정본 7장의 대량 배포 금지와 같은 일이다. 채널마다 말투를 다르게 한다
- 사실은 원문을 확인한 것만 올린다. 출처와 날짜를 붙인다(우물가 원칙과 같음)

### 정기 리듬 — 주 3회, 지킬 수 있는 만큼

| 요일 | 내용 | 재료 |
|---|---|---|
| 월 | 이번 주 알아 둘 것 — 사기 경보·무료 행사 | 헤브론 우물가 |
| 수 | 한 사람의 정착 이야기 또는 한 도시의 장면 | 이야기 올리기 · 도시 가이드 |
| 금 | 이번 주 식탁의 자리 | gathering (시애틀부터) |

## 5. 첫 90일 — 정본 8장 순서대로

| 기간 | 할 일 |
|---|---|
| 1~2주 | 1장의 "막을 것" 다섯 가지를 닫는다. 로그인하지 않은 창에서 AI에게 "HebronGuide가 뭐야?", "시애틀 한인 가정교회 추천해줘"를 묻고 지금 답을 기록한다(출발선) |

| 5~8주 | 시애틀에서 식탁 초대가 매주 1곳 이상 열리게 한다. 의견 상자로 들어온 것 중 고친 것을 우물가에 알린다 |
| 9~12주 | 2단계 채널(페이스북·밴드). 로그인하지 않은 창 질문을 다시 해 출발선과 비교한다(정본 3장 분기 자가진단) |
