> **"HebronGuide가 정말 새 이주자, 이민자, 유학생, 정착자 등에게 도움이 되는 플랫폼이야?

## 왜 5명인가

5명이면 같은 답이 반복되기 시작한다. 10명 하면 더 정확해지지만 **5명에서 이미 방향이 보인다.**
중요한 건 숫자가 아니라 **누구에게 어떻게 묻느냐**다.

---

## 누구에게 묻는가

### ✅ 맞는 대상
- **최근 1년 안에** 새 도시로 이주한 사람 (이민·유학·주재원·역이민 무관)
- 아직 정착 중이거나, 정착한 지 얼마 안 된 사람
- **HebronGuide를 모르는 사람이 더 좋다**

### ❌ 피해야 할 대상
| 대상 | 왜 안 되는가 |
|---|---|
| 파트너 교회 목사님 | 목사님을 아껴서 좋게 말한다. 진실이 안 나온다 |
| 이미 HebronGuide를 아는 지인 | 예의상 "좋아요"라고 한다 |
| 이주한 지 5년 넘은 사람 | 그때 뭘 했는지 기억이 왜곡돼 있다 |
| 가족 | 가장 부정확하다 |

> **핵심: 나를 실망시켜도 괜찮은 사람에게 물어야 진실이 나온다.**

### 어디서 찾나
- 파트너 교회에 **"최근 오신 분 소개해 주세요"** (목사님이 아니라 그분에게 직접 묻는다)
- 도시별 카카오 오픈채팅의 새 멤버
- 유학생 커뮤니티

## 인터뷰 3대 규칙 (이걸 어기면 결과가 무의미해진다)

### 규칙 1 — 절대 먼저 홍보하지 않는다
HebronGuide 이야기는 **맨 마지막**에 꺼낸다. 먼저 말하면 그 순간부터 상대는 **예의를 지키기 시작**하고, 진짜 행동은 영영 안 나온다.

### 규칙 2 — 미래가 아니라 과거를 묻는다

| ❌ 이렇게 묻지 말 것 | ✅ 이렇게 물을 것 |
|---|---|
| "이런 사이트 있으면 쓰시겠어요?" | "지난번 병원 찾을 때 어떻게 하셨어요?" |
| "도움이 될까요?" | "제일 힘들었던 게 뭐였어요?" |
| "필요하세요?" | "그때 누구한테 물어보셨어요?" |

> 미래 질문에는 **모두가 예의상 '네'라고 한다.** 과거 행동은 거짓말을 못 한다.

### 규칙 3 — 구체적으로 파고든다
"인터넷에서 찾았어요" 에서 멈추지 말 것.
→ **"어떤 사이트요?"** → **"검색어를 뭐라고 치셨어요?"** → **"그래서 찾으셨어요?"**

## 질문 순서

### 1부 — 실제로 무엇을 했나 (HebronGuide 언급 절대 금지)

```
1. 언제, 어느 도시로 오셨어요?

2. 도착하고 첫 한 달, 제일 막막했던 게 뭐였어요?
   → (하나 말하면) 또 뭐가 있었어요?  ← 2~3개 나올 때까지

3. 그 문제를 결국 어떻게 해결하셨어요?
   → 누가 도와줬어요?  (사람 이름·관계까지)

4. 정보는 주로 어디서 찾으셨어요?
   → 구체적으로 어떤 사이트/앱/단톡방이요?
   → 검색은 뭐라고 치셨어요?

5. 그때 "이런 게 있었으면 좋았을 텐데" 싶었던 게 있어요?

6. 교회는 어떻게 찾으셨어요? (혹은 왜 안 찾으셨어요?)
```

### 2부 — 알고 있나 (여기서 처음 언급)

```
7. 혹시 'HebronGuide'라고 들어보셨어요?
```

| 답 | 다음 질문 |
|---|---|
| **모른다** | → 3부로. **유통 문제**다 |
| **안다** | → "어떻게 아셨어요?" → "써보셨어요?" |
| **써봤다** | → "언제, 뭘 하려고요?" → "그래서 도움이 됐어요?" → "그 뒤로 또 쓰셨어요?" |

> **"안다"고 하는데 "안 썼다"면 — 가치 문제다. 이게 가장 중요한 신호.**

### 3부 — 보여주고 반응 보기

휴대폰으로 **그분 도시 페이지**를 열어 보여준다. **설명하지 말고 그냥 건넨다.**

```
8. (2분 정도 말없이 지켜본다)
   - 어디를 먼저 누르나?
   - 어디서 멈추나?
   - 표정이 언제 바뀌나?

9. 솔직히 어떠세요? 좋게 말 안 하셔도 돼요.

10. 이거, 도착하시기 전에 알았다면 쓰셨을 것 같아요?
    → "왜요?" / "왜 안 쓰셨을 것 같아요?"   ← 이유가 핵심

11. 이걸 아는 사람에게 알려주고 싶으세요?
    → 누구한테요? / 왜 아닐 것 같아요?
```

### 마무리 — 가장 중요한 질문

```
12. 지금 막 도착한 친구가 있다면, 뭐라고 알려주시겠어요?
```
> 이 답에 **HebronGuide가 안 나오면** — 아직 필요한 것이 아니다. 그게 답이다.

## 결과 읽는 법

5명 끝나면 아래로 판정한다.

| 나온 결과 | 진단 | 다음 할 일 |
|---|---|---|
| **5명 다 모른다** | **유통 문제** — 물건은 있는데 가게가 골목에 있다 | 사람들이 실제 있는 곳(카톡 오픈채팅·교회 주보·한인회)에 들어간다. 기능 추가 ❌ |
| **알지만 안 썼다** | **가치 문제** — 가장 아프지만 가장 중요한 신호 | "왜 안 썼는지" 그 이유가 곧 만들어야 할 것 |
| **썼는데 한 번뿐** | **지속성 문제** — 첫날만 쓰고 끝 | 정착 이후에도 남을 이유(사람·공동체)가 필요 |
| **"사람이 필요했다"가 반복** | **방향 확인** — 정보가 아니라 사람 | [`PLATFORM_PRINCIPLES.md`](PLATFORM_PRINCIPLES.md) 원칙1 대로 사람 연결로 |
| **2명 이상이 자발적으로 "이거 좋다"** | **진짜 신호** | 그 2명이 왜 좋다 했는지, 그것만 남기고 나머지는 줄인다 |

### 주의 — 이렇게 자신을 속이기 쉽다
- ❌ "홍보를 더 하면 되겠다" ← 5명이 **보고도** 안 쓰겠다 하면 홍보 문제가 아니다
- ❌ "기능이 부족해서" ← AI 질문 0건. 기능은 이미 안 쓰이고 있다
- ❌ 좋게 말한 1명만 기억하기 ← 5명 전체를 놓고 봐야 한다
