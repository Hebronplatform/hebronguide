# HebronGuide 커뮤니티 리서치·공략 전략

> **대표님 지시 (2026-10-17)**:
> "미국 사는 한국인 그룹을 통해 한인들의 특징과 문화, 필요를 찾아
>  타겟 대상의 필요를 찾아 채우는 공략 준비에 도움이 될 듯."
>
> **이 문서의 역할**: 커뮤니티를 **유입 경로**뿐 아니라 **리서치 소스**로 활용.
> 수집한 인사이트를 Hebron 콘텐츠·FAQ·AI에 반영하는 플로우.

## 1 · 왜 커뮤니티 리서치가 중요한가

### 지금의 한계
- 저가 작성한 FAQ 14문항은 **일반적 지식 기반**
- 실제 재외 한인의 **진짜 고민·필요**는 저가 다 알 수 없음
- "어떤 질문을 가장 많이 하는지" 모르면 **엉뚱한 콘텐츠**를 만들 가능성

### 커뮤니티가 해결하는 것
- **"미국 사는 한국인"** 같은 그룹의 **실제 질문·댓글·불만**이 **데이터 금광**
- 매일 수백 건의 **"지금 뭐가 고민인가"** 흐름이 노출됨
- Hebron은 그 흐름에서 **반복되는 패턴**을 추출해 콘텐츠로 녹임

### 결과
- **"수요가 입증된 콘텐츠"** 만 제작 → 노력 효율
- **"그 사람들이 쓰는 언어"** 로 답변 → 거부감 X
- **공략 포인트** 파악 → 수익·홍보 전략 집중

## 3 · 어떤 신호를 찾을지 (리서치 템플릿)

### A. **질문의 유형별 집계**
매일/매주 올라오는 질문을 다음 카테고리로 분류:

| 카테고리 | 예시 질문 | Hebron FAQ 반영 |
|---|---|---|
| **행정·비자** | "H-1B 추첨 떨어졌는데..." / "영주권 I-485 EAD" | 이민 FAQ·공식 Q&A |
| **운전면허** | "주 간 이사하면 면허 어떻게?" | 각 도시 FAQ #4 보강 |
| **학교·학군** | "린우드 초등 어디가?" / "ESL 입학" | 각 도시 FAQ #10 보강 |
| **의료·보험** | "ACA 플랜 추천?" / "한국어 의사" | 각 도시 FAQ #13 보강 |
| **세금** | "FBAR·FATCA 어떻게?" | Seattle+ Q&A 공식 섹션 |
| **주거·렌트** | "이 동네 안전?" | 각 도시 FAQ #9·#6 보강 |
| **육아·교육** | "SAT 학원?" / "ESL 아이 적응" | 특화 콘텐츠 신설 |
| **교회·커뮤니티** | "우리 지역 한인 교회?" | Hebron Churches 디렉토리 |
| **차량·운송** | "중고차 추천 플랫폼?" | 각 도시 FAQ 보강 |
| **쇼핑·마트** | "H Mart 외 어디?" | 각 도시 FAQ #1 보강 |
| **감정·심리** | "외롭다" / "적응 힘들다" | 환대의 식탁·voices.html |

### B. **반복 패턴 추출**
- **"이 질문이 매주 2번 이상"** → Hebron FAQ Top 추가
- **"같은 지역에서 반복"** → 그 도시 콘텐츠 집중 보강
- **"답변 X 질문"** → Hebron이 공백 메우기 (경쟁력)

### C. **언어·톤 분석**
- 한국어 vs 한글화된 영어 비율
- 존댓말 vs 반말
- 이모티콘·줄임말 사용
- "~해주세요"·"~있을까요?" 등 전형 표현
→ **Hebron 콘텐츠 톤 조정**

### D. **감정 신호**
- 긍정·중립·부정 비율
- 불만·불안·분노의 트리거 (어떤 상황에서 폭발?)
→ **환대 식탁·심리 지원 콘텐츠** 설계

### E. **공유된 외부 링크**
- 어떤 사이트가 자주 공유되는지
- Hebron 라운지에 **추가할 커뮤니티 발견**
- 경쟁 자산 분석

## 4 · 수집·분석 방법

### 방법 1 · **수동 모니터링** (지금 즉시 가능)
- 대표님(또는 자원봉사자)이 **매주 1-2시간** 각 커뮤니티 피드 스크롤
- 질문을 **분류 표** (위 A)에 집계
- **Google Sheet** 하나로 관리 (`research-tracker.gsheet`)
- 월말에 Top 10 질문 → Hebron FAQ 반영

**장점**: 공짜·즉시·법적 안전
**단점**: 시간 소모·주관성·누락 가능

### 방법 2 · **반자동 (브라우저 확장 + 수동 집계)**
- Facebook 그룹 피드를 **Chrome 확장** (예: Group Collector)으로 export
- CSV 다운로드 → Excel/Sheet 분석
- 또는 **스크린샷·태그 수집** 도구

**장점**: 수동보다 효율·대량 처리
**단점**: 플랫폼 TOS 준수 필요·개인정보 주의

### 방법 3 · **AI 분석 — Hebron AI 로드맵과 통합** (중기)
- **공개 데이터만** 수집 (게시물 비공개 X·개인 식별 X)
- 수집한 질문을 Claude API로 **카테고리 자동 분류**
- 월별 **"재외 한인 Top 10 질문" 자동 리포트**
- `scripts/community-pulse.mjs` 신설 가능

**장점**: 대규모·반복 가능
**단점**: 플랫폼 API/스크레이핑 정책·개인정보·법적 검토 필요

### 방법 4 · **직접 참여형 리서치** (대표님 자신이 가장 큰 자산)
- 대표님이 **"미국 사는 한국인"** 등에서 활동
- 직접 질문 올림: "**어떤 정보가 가장 아쉬우세요?**"
- 받은 답변을 Hebron 콘텐츠로 반영
- **대표님 이름·역할 공개** (신뢰·credibility)

**장점**: 가장 정직·신뢰 쌓음·즉시 피드백
**단점**: 시간 투자·답장 필요·운영자 관계 중요

## 5 · Hebron 반영 플로우 (리서치 → 액션)

```
Step 1 · 수집 (매주)
  각 커뮤니티 피드 모니터링 (대표님 또는 자원봉사자)
  → 분류 표에 질문 집계
         ↓
Step 2 · 분석 (매월)
  Top 10 반복 질문·공백 영역·감정 신호 분석
  → 우선순위 순위
         ↓
Step 3 · 콘텐츠 제작 (매월 2-4건)
  Top 질문에 대한 Hebron 답변 작성
  → 해당 도시 FAQ·Seattle+ 공식 Q&A·voices 사례 추가
         ↓
Step 4 · 환류 (매월)
  답변 완성 후 해당 커뮤니티에 다시 공유 (가치 선물)
  "이번 달 많이 묻는 질문에 답변 모음" → 유입
         ↓
Step 5 · 측정 (분기)
  어느 콘텐츠가 가장 유입·공유·광고 전환 발생?
  → 다음 분기 리서치 방향 조정
```

## 6 · 민감 데이터·개인정보 보호 (중요)

### 반드시 지킬 것
- **공개된 데이터만** 수집 (비공개 메시지·DM·그룹 비공개 게시물 X)
- **개인 식별 X** — 이름·사진·계정 저장 X
- **익명화** — 질문은 **"어떤 패턴이 있는지"**로만 집계, 원글 복제 X
- **플랫폼 TOS 준수** — Facebook·Reddit·네이버 각기 데이터 사용 정책 다름
- **GDPR·CCPA·한국 개인정보보호법** 준수

### Hebron 콘텐츠 반영 시
- 특정 질문자 인용 X (예: "ㅇㅇ님이 그러셨는데..." 금지)
- 일반화된 패턴만 사용 (예: "많은 분이 이런 질문을 해 주셔서...")
- 원글 링크 복붙 X (저작권 위반)
- Hebron이 재구성한 **독립적 콘텐츠**만 공개

### 법적 리스크 체크
- 리서치 결과를 **상업적**으로 활용 전 변호사 자문 권장
- "커뮤니티에서 얻은 데이터로 광고 수익" → 모호한 영역
- 안전지대: **"공공 사실 기반 콘텐츠 개선"**은 명백히 OK

### 12.6 공략 효과 측정 (A/B 식)

**인과 측정**:
- Hebron이 특정 질문에 답변 콘텐츠 신설 → 한 달 뒤 **같은 질문 다시 올라오는 횟수 감소하나?**
- 공유 콘텐츠 발행 → 한 달 뒤 **커뮤니티에서 Hebron 언급 증가하나?**
- 광고 CTA 노출 → **광고 신청 전환율 변화?**

**지표**:
| 전후 비교 | 측정 |
|---|---|
| Hebron 답변 신설 후 같은 질문 반복 | **감소율** = (전월 반복 - 당월 반복) / 전월 반복 × 100 |
| 공유 콘텐츠 발행 후 Hebron 언급 | **언급 증가율** = (당월 언급 - 전월 언급) / 전월 언급 × 100 |
| 광고 CTA 노출 → 신청 | **CTR** = 신청 수 / CTA 노출 수 × 100 |
