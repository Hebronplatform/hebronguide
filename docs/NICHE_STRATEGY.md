# 틈새 — 아무도 밥상을 차려주지 않는다

**정립: 2026-08-11**

> 이 문서는 **하고 싶은 일**이 아니라 **실제로 가진 것**에서 출발합니다.
> 오늘 확인한 0들(AI 질문 0 · 이야기 0 · 자발적 가입 0)이 이 문서를 쓰게 했습니다.

## 2. 사례에서 뽑은 다섯 가지

### ✗ Quibi — 돈이 문제가 아니었다

거액의 투자, 유명 배우, 완성도 높은 기술. **6개월 만에 접었습니다.**
이유는 하나 — **아무도 원하지 않았습니다.** 그리고 그들은 출시하기 전까지 몰랐습니다.

> **우리의 0과 같은 병입니다.** 만드는 것이 문제가 아니라, 필요한지 묻지 않은 것이 문제입니다.
> → [`USER_VALIDATION_INTERVIEW.md`](USER_VALIDATION_INTERVIEW.md) 5명 인터뷰가 여기서 나왔습니다.

### ✓ Duolingo — 무료를 지키면서 돈을 벌었다 ★ 카우치서핑의 반대

| 카우치서핑 | Duolingo |
|---|---|
| 무료였다가 **결제벽을 세움** | 핵심 기능은 **끝까지 무료** |
| 있던 것을 뺏음 | **더할 것만** 유료·광고 |
| 예고 없음 | 무료 사용자는 잃은 게 없다 |
| **커뮤니티 붕괴** | 반발 없이 수익화 |

> **광고를 넣을 때 이 표를 다시 보십시오.**
> 목사님이 하신 말씀 — *"나중에는 광고가 들어가야 수입이 생겨서 이것을 계속 만들지"* — 는 맞습니다.
> 다만 **Duolingo 방식이어야 합니다.**

### ✓ Craigslist — 못생긴 채로 20년

디자인을 거의 바꾸지 않았고, 대부분 무료이고, 여전히 살아 있습니다.
**단순함과 일관성이 기능보다 오래갑니다.**

> HebronGuide가 배울 것: 화면을 더 만들기 전에, **있는 화면이 실제로 쓰이는지** 먼저 봅니다.

### ✓ Wikipedia — 신뢰가 곧 자산

광고를 팔지 않고 기부로 버팁니다. 자원봉사자가 씁니다.
**돈을 받지 않는다는 사실 자체가 신뢰의 근거**가 되었습니다.

> 「이 목록은 돈으로 살 수 없습니다」와 같은 사상입니다.

### ✗ Segway — 만든 사람만 혁명이라 믿었다

발명자는 도시를 바꿀 거라 했습니다. 사람들은 그냥 걸었습니다.
**"이건 대단하다"는 만든 사람의 감정이지 사용자의 필요가 아닙니다.**

## 3. 틈새는 어디인가

### 이미 남이 잘하는 것 — 들어가면 진다

| 영역 | 이미 있는 곳 | 우리 위치 |
|---|---|---|
| 정착 정보 게시판 | 라디오코리아 · 미시USA · 한인 카페 | **이길 수 없다** |
| 업소 디렉토리 | 위 + 구글 · Yelp | **업소 3개. 경쟁 자체가 안 된다** |
| 중고 거래 | 당근 · Facebook Marketplace | 들어가지 않는다 |

### 우리가 압도적인 것

```
한인 교회 959개.
이만큼 모아둔 곳이 없습니다.
```

### 그런데 진짜 틈새는 교회 목록이 아닙니다

교회 목록도 이미 여기저기 있습니다. **아무도 안 하는 것은 이것입니다.**

> ## 도착한 첫 주에, 혼자 밥 먹지 않게 하는 것

라디오코리아는 **정보**를 줍니다. 자리를 주지 않습니다.
교회는 **예배**로 부릅니다. 믿음이 없으면 문턱이 높습니다.
한인회는 **행사**를 합니다. 매주가 아닙니다.

```
정보는 넘치는데,
이번 주 금요일 저녁에 앉을 식탁이 없습니다.
```

**그것이 틈새이고, [gathering.html](../gathering.html) 이 정확히 그 자리입니다.**

## 5. 지금 하지 말아야 할 것 ★ 가장 중요

오늘 하루만 봐도 제가 화면을 여덟 개 고쳤습니다.
**화면이 부족해서 0이 된 것이 아닙니다.**

| 하지 않는다 | 왜 |
|---|---|
| 새 도시 추가 | 81개도 절반이 비어 있다 |
| 업소 모집 캠페인 | 3개 → 30개가 되어도 954개와 경쟁 안 됨 |
| 새 기능 | AI 질문 0, 이야기 0. 있는 것도 안 쓴다 |
| SEO·광고 집행 | 와도 앉을 자리가 없다 |
| 수익 모델 설계 | 아직 한 사람에게도 닿지 못했다 |

> **Quibi는 돈과 기술이 다 있었는데 필요가 없어서 죽었습니다.**
> 우리는 돈은 없지만 같은 병에 걸릴 수 있습니다.

## 6. 수익은 나중에, 그러나 방식은 지금 정한다

지금 수익 모델을 짤 때가 아닙니다. 다만 **원칙은 지금 못박아야** 나중에 흔들리지 않습니다.

```
① 지금 무료인 것은 영구 무료      — 찾기 · 등록
② 광고는 더하는 것, 뺏는 것이 아니다
③ 광고와 순위를 절대 섞지 않는다  ← Yelp가 잃은 것
④ 최소 한 달 전 예고               ← 카우치서핑이 안 한 것
```

상업 팔(웹 제작·컨설팅)과 사명 팔(앱)의 분리는
[`REVENUE_STRATEGY.md`](REVENUE_STRATEGY.md)에 이미 있습니다. 그대로 둡니다.
