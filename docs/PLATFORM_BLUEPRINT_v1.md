## ① 세 줄 요약

1. **남긴다** — 정착 정보·교회·도움은 이미 충실하다. 이것들은 그대로 두고 **앞에 세우는 순서**만 바꾼다.
2. **뺀다** — 광고 팝업, 근거 없는 숫자 띠, 설치 배너 세 개, 쓰지 않는 화면 조각과 "준비 중" 카드. 도시 홈 첫 화면의 눈에 띄는 버튼을 **다섯 개에서 하나로** 줄인다.
3. **새로 온 사람에게 달라지는 것** — 지금은 "사람 이어 주기"(도착 신청)와 "식탁"이 앱 안에 거의 보이지 않는다. 바뀐 뒤에는 **어느 도시에서든 첫 화면 단 하나의 버튼이 "한 사람 이어 드릴게요"**가 된다.

## ② 걸어 본 기록 — 가상 인물 넷

> 눌러 본 곳은 2026-10-29 라이브 사이트(휴대폰 화면 375px)다.

### 첫 문(1면 `hebronguide.com`)에서 모두가 겪는 일

- **이게 뭔지 글자로 보이지 않는다.** 지구 그림과 "내 도시로 바로 가기" 버튼뿐이다. 설명 문장(H1)은 화면 읽기 프로그램에만 보이게 숨겨져 있다.
- **"내 도시"가 엉뚱한 곳으로 간다.** 위치 권한이 없으면 시간대로 추측한다. 그래서 시애틀에 사는 사람이 **LA**로 가고, **한국에서 이사를 준비하는 사람은 "서울"**로 간다. 새로 올 사람에게 필요한 건 "지금 있는 곳"이 아니라 **"가려는 곳"**이다.
- **10초 뒤 광고 팝업이 뜬다.** "가게·사역·행사를 한인에게 알리시겠어요? 월 $9.99 — 광고 신청". 막 도착한 사람의 첫 문에 광고 영업이 선다.
- 1면 아래 탭(도시·도착·도움·더보기)과 도시 앱 아래 탭(홈·정착·탐방·도움·더보기)이 **서로 다르다.** 1면의 "도착"은 앱 안에는 없다.

```
   81개 도시에서 먼저 온 사람들이 기다립니다.

   ┌─────────────────────────────┐
   │   어느 도시로 가세요?        │  ← 하나뿐인 강조 버튼
   └─────────────────────────────┘
   이미 살고 있어요 · 돕고 싶어요            ← 글자 링크

   (아래 탭 없앰 — 앱의 아래 탭과 겹치지 않게)
```

- "내 도시로 바로 가기"(현재 위치 추측) → **"어느 도시로 가세요?"**(검색창이 열리고 최근 도시·주요 도시 6개). 위치 추측은 "가까운 도시" 작은 글자로만.
- 광고 팝업과 맨 위 행사 띠는 1면에서 뺀다(행사는 게시판에).
- 서랍 메뉴는 두 묶음으로: **처음 오신 분**(도착·자주 묻는 질문·이야기) / **함께하는 분**(교회 등재·자원봉사·후원·나누리웹). "광고 신청"은 뺀다.

### 도시 홈 — 아침, 밝게

```
[로고  시애틀 ▾]                                  [검색] [Aa]
┌───────────────────────────────────────────┐
│ (시애틀 사진)                                 │
│ 시애틀에 오신 것을 환영합니다                    │
│ 먼저 온 사람이 기다리고 있어요                    │
│ ┌───────────────────────────────┐          │
│ │  한 사람 이어 드릴게요            │ ← 유일한 강조 버튼
│ └───────────────────────────────┘          │
└───────────────────────────────────────────┘
 이번 주
 ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
 │ 첫 주 할 일    │ │ 식탁의 자리    │ │ 교회 찾기      │  ← 같은 무게의 흰 카드(강조색 없음)
 │ n / 16        │ │ 이번 주 n곳    │ │ n곳           │
 └──────────────┘ └──────────────┘ └──────────────┘
 [ 교회 · 병원 · 은행 · 집 찾기          ]  ← 검색(흰 칸, 테두리만)
 생활 정보 전체 보기 ›                         ← 집·면허·병원·학교·일·생활비·맛집·탐방
 ─────────────
 곧 이 도시로 오는 분이 떠오르나요? 함께 나누기 ›   ← 글자 링크로 낮춤
```

- **강조 버튼 하나**: "한 사람 이어 드릴게요". 앱 안 3단계 양식(무엇이 막막한지 → 부를 이름과 연락처 → 보내기)으로 연결되고, 도시는 미리 채워진다. 기존 `arrive.html`과 같은 곳(`community_items`, type `arrive`)에 쌓인다.
- **식탁 카드**: 모임이 있으면 "이번 주 n곳", 없으면 "자리를 알아봐 드려요"로 같은 도착 양식에 연결한다. 시애틀 외 도시에서도 카드는 보이고, 시트가 생기면 숫자가 뜬다.
- **지우는 것**: 오래된 "새 기능" 초록 띠(5월 문구) · 숫자 띠 · "글로벌 환대 플랫폼" 배지 · 설치 배너 세 개 중 둘(하나만, 두 번째 방문부터).

### 아래 탭 — 다섯 개 → 네 개

| 지금 | 바뀐 뒤 |
|---|---|
| 홈 · 정착 · 탐방 · 도움 · 더보기 | **홈 · 첫 주 · 사람 · 도움** |

- **첫 주** = 지금의 정착 탭(시기별)
- **사람** = 교회 + 식탁 + 사람 연결 + 도울게요. 송곳 목표가 탭 하나를 갖는다
- **도움** = 긴급·병원·법률·지원기관
- 탐방·맛집·취업·교육·생활비·업소는 홈의 "생활 정보 전체 보기"와 검색으로

### 흐름은 모두 3단계 이하

| 흐름 | 지금 | 바뀐 뒤 |
|---|---|---|
| 한 사람 이어 받기 | 앱 안에 없음(1면 → 별도 페이지) | 홈 버튼 → 막막한 것 → 이름·연락처 → 보내기 (**3**) |
| 식탁 | 홈→교회→배너(시애틀, 모임 있을 때만) | 홈 카드 → 모임 고르기 → 연락 (**3**) |
| 교회 새가족 신청 | 3번 + 앱 밖으로 나감 | 사람 → 교회 → 새가족 신청(앱 안 짧은 양식) (**3**) |
| 사기 경보 | 정착 아홉째 칸(옆으로 밀어야) | 첫 주 탭 맨 위 한 줄 "이번 주 조심할 것" (**1**) |

## ⑨ 무료 가입 — 추천: "가입 없이 다 보이게, 가입은 저장할 때만"

**가입을 입구에 두지 않는다.**
- 막 도착한 사람에게 가입부터 요구하면 그 자리에서 돌아선다.
- 성경의 설계는 "나그네의 문턱은 낮게, 검증의 무게는 주는 쪽에"다(`TRUST_CHAIN.md`, 레 19:34).
- 이미 가진 원칙 "3단계 이하"와도 부딪힌다.

**대신 "내 정착 노트"를 무료로 둔다** — 원할 때만, 비밀번호 없이.

| 회원이 아니어도 | 무료 회원이면 |
|---|---|
| 모든 정보 · 교회 · 식탁 · 도움 · 도착 신청 | 체크리스트가 기기를 바꿔도 남음 |
| 체크리스트(그 기기 안에만) | 도착일에 맞춘 "이번 주 할 일" 메일(주 1회) |
| | 내가 보낸 도착·새가족 신청이 어디까지 왔는지 |

- 가입 방법은 **이메일 주소 하나 → 받은 링크 누르기**(Supabase 로그인 기능 사용, 서버 함수 추가 없음).
- 모으는 것은 이메일과 도시뿐이다. **팔지 않고 다른 데 쓰지 않는다**(마 10:16).
- **선행 조건 두 가지**: ① 전용 메일 발송 서비스(`MARKETING_LAUNCH_READINESS.md` 막을 것 4번) ② 개인정보 처리방침 개정. 그래서 순서는 ⑦의 8단계, 맨 뒤다.

## ⑩ 하나뿐인 지표를 재는 법

> **이번 주 혼자 밥 먹지 않은 사람 수**

개인을 따라다니지 않고, **사람이 확인한 연결만** 센다.

1. 도착 신청(`community_items`, type `arrive`)에 상태 칸을 쓴다: `pending → connected → ate-together`. 관리자 화면에서 목사님이나 목자가 바꾼다. 기존 `admin-action` 함수를 쓰므로 새 함수가 필요 없다.
2. 식탁 시트에 "이번 주 처음 온 분 수" 칸 하나를 둔다. 목자가 숫자만 적고, 이름은 적지 않는다.
3. 월요일 주간 보고(⑧)가 두 숫자를 더해 보여 준다.

방문자 수와 소개 횟수는 세지 않는다. 지금 요금제로는 셀 수 없고, 목표와도 다르다.
