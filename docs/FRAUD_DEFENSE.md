# 사기 방어 — 신뢰를 빌려 쓰지 못하게

**정립: 2026-08-11 | KBS 중고거래 사기 취재 분석 → HebronGuide 적용**

> **"여기는 아직도 미지의 개척지, 시장성이 높다고 보고 있기 때문에**
> **보이스피싱을 하던 조직들이 블루 오션을 발견한 거죠."**
> — 방송 中 전문가

---

## 왜 우리가 이걸 해야 하는가

전문가의 결론은 분명했습니다.

> *"엄청나게 많은 사람이 사기를 당하는데 우리는 모른다, 이렇게 수수방관할 수 있는 시대는 지났다."*
> *"플랫폼이 막대한 수수료와 광고수익을 거두고 있는 만큼 피해 예방에 적극 나서야 한다."*

**우리는 수수료를 받지 않습니다. 그래도 책임은 같습니다.**
연결하는 순간 책임이 생기기 때문입니다.

### 그리고 우리에게는 더 큰 이유가 있습니다

HebronGuide의 자산은 **"돈으로 살 수 없는 목록"** 하나뿐입니다.
사기꾼이 한 명 등재되는 순간, 그는 **우리 신뢰를 빌려 씁니다.**

```
"HebronGuide에 있는 업소인데요"
        ↓
새로 온 사람이 의심을 내려놓는다
        ↓
우리가 만든 신뢰가 사기의 도구가 된다
```

**이것이 우리가 잃을 수 있는 전부입니다.**

---

## 새 이민자가 특히 취약한 이유

방송에 나오지 않은 부분입니다. 우리만 압니다.

| | |
|---|---|
| **시기** | 도착 첫 달에 가구·가전·차를 전부 중고로 산다 |
| **정보** | 시세를 모른다. 비싼지 싼지 판단이 안 선다 |
| **방심** | "같은 한국 사람인데" — 한인 단톡방 거래 |
| **언어** | 영어가 안 돼 신고를 못 한다 |
| **두려움** | 체류 신분 걱정으로 경찰을 꺼린다 |

마지막 줄이 핵심입니다. **신고하지 않으니 통계에 안 잡히고, 안 잡히니 아무도 안 지켜줍니다.**
그래서 앱에 이 한 줄을 넣었습니다:

> **체류 신분과 상관없이 신고할 수 있습니다. 피해자는 처벌받지 않습니다.**

## 세 겹 방어

### 1겹 — 예방 (새로 온 사람에게)

**앱 · 도움 화면 · 전국 공통 카드** — 「중고거래 사기 주의」

방송의 한국 수법을 미국·캐나다 맥락으로 옮겼습니다.

| 방송(한국) | HebronGuide(미국) |
|---|---|
| 계좌이체 취소 불가 | **Zelle·Venmo·Cash App** — 보낸 뒤 되돌릴 수 없음 |
| 가짜 안전결제 사이트 | **앱 밖 '결제 링크'는 전부 사기** |
| 3자 사기(판매자·구매자 동시 기만) | **"대리인을 보낸다"면 거절** |
| 인증샷 합성 | **영상통화로 물건을 보여달라** |
| — | **경찰서 Safe Exchange Zone** (미국 고유) |

신고처: **IC3.gov** (FBI) · **reportfraud.ftc.gov** (FTC)

### 2겹 — 색출 (등록 심사)

`api/register-business.js` 의 `scanRisk()` 가 **등록 즉시** 신호를 셉니다.

| 신호 | 왜 위험한가 |
|---|---|
| 전화번호 없음 · 주소 없음 | 실체를 확인할 방법이 없다 |
| **전화 없이 카톡·텔레그램만** | 추적 안 되는 채널만 남기는 건 전형적 사기 패턴 |
| 선입금·계좌이체·Zelle 유도 | 돈을 먼저 보내게 하는 말 |
| 급처·오늘만·선착순 | 조급하게 만든다 (방송에서 반복 확인) |
| 100% 보장·반값·최저가 | *"5만원 생각했는데 2만원"* 이 첫 신호였다 |
| 소개가 10자 미만 | 실제로 운영하는 곳은 할 말이 있다 |

점수 = `100 - 신호수 × 18`. `tags` 와 `confidence_score` 에 남고,
**관리자 대시보드가 승인 버튼 옆에 배지로 보여줍니다.**

> ### ⚠️ 자동 거절하지 않는다 — 이것이 설계의 핵심입니다
>
> **한인 소상공인은 실제로 카톡으로 영업하고 홈페이지가 없습니다.**
> 기계가 자르면 **정직한 사람이 먼저 잘립니다.**
>
> 실제 시험 결과:
> ```
> 정상 한식당              100  신호 없음
> 홈페이지 없는 미용실     100  신호 없음   ← 정직한 소상공인은 안 걸린다
> 카톡만 있는 곳            46  전화·주소 없음, 추적 불가
> 선입금·급처·100% 보장     10  신호 5개
> ```
>
> **신호를 보여주되 판단은 사람이 합니다.** `CITY_ENGINE_V2` 의 사람 게이트 원칙과 같습니다.

### 3겹 — 배제 (조치)

| 단계 | 조치 |
|---|---|
| 신호 3개 이상 | 승인 보류. 전화로 실체 확인 후 판단 |
| 이단 키워드 적중 | **즉시 거절** (자동, 사람 판단 불필요) |
| 등재 후 피해 신고 접수 | **즉시 비공개** 전환 후 조사 |
| 확인된 사기 | 삭제 + 전화·이메일 기록 보존 (재등록 차단) |

> **방송의 교훈** — 민간 플랫폼 '더치트'가 경찰 통계의 **3배**를 잡아냈습니다.
> **피해자 신고가 가장 빠른 색출 장치입니다.** 신고 창구를 눈에 띄게 두는 것이
> 어떤 자동 탐지보다 강합니다.

## 아직 안 한 것 (다음 순서)

- [ ] **피해 신고 창구** — 지금은 신고할 자리가 없다. 3겹 중 가장 강한 장치가 비어 있다
- [ ] **같은 전화·이메일로 여러 건 등록** 감지 — 대량 등록은 조직 사기의 신호
- [ ] `submit-listing.js` 자동 승인 경로에 같은 검사 적용 (지금은 업소 등록에만)
- [ ] **목장 모임 시트** — 낯선 사람을 개인 집으로 부르는 자리. 편집 권한 관리가 곧 안전

## 마케팅으로 보면

경쟁 플랫폼과의 차이가 여기서 갈립니다.

```
Facebook Marketplace · 당근  →  누구나 올린다.  빠르다.  사기가 많다.
HebronGuide                →  사람이 승인한다. 느리다.  그래서 믿을 수 있다.
```

**느린 것이 약점이 아니라 상품입니다.**
방송의 중고의류 회사가 증명했습니다 — 검수·세탁·살균·택·포장을 거치니
같은 중고 옷인데 *"새 옷 받는 기쁨"* 이 되었습니다.

> **「이 목록은 돈으로 살 수 없습니다」의 짝은**
> **「이 목록에는 사기꾼이 들어올 수 없습니다」입니다.**
