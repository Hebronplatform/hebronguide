## 응답 받은 뒤 다음 단계

**긍정 응답 → 즉시 액션**:
1. 해당 커뮤니티를 Hebron 라운지(`hebronguide/public/lounge-sites.json`)에 등재
2. 운영자에게 등재 링크 공유 → 확인·수정 요청 받기
3. 공유 가능한 Hebron 콘텐츠 추천 (해당 커뮤니티 특성에 맞는)
4. 그룹별 전용 랜딩(`/from/{slug}/`) 설정해 유입 추적

**거절 응답 → 존중**:
1. 감사 메일 한 통 → 종료
2. Hebron 라운지에서 **등재하지 않음**
3. 리스트에서 제외 기록

**무응답 → 2주 뒤 1회 리마인드**:
1. 짧게 "지난 메일 재전송·검토 부탁드립니다" 수준
2. 2회째 무응답 → 포기, 다른 커뮤니티로 이동
