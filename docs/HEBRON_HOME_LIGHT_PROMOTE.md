## 승격의 효과

### 긍정
1. **디자인 정체성 즉시 전달** — Hebron이 "클로드 디자인 복제"로 보일 가능성 제거. 사용자 "창의적 변화" 요구에 가장 명확한 응답.
2. **보도자료·뉴스레터 론칭과 톤 일치** — Phase 2 올인 전략과 어울림.
3. **라이트/다크 토글** — 사용자가 환경 조절 가능.
4. **Seattle+ · 라운지 · 지도 · 분광 네 입구 평등 노출** — 수익(광고 신청)·커뮤니티(라운지 공유) 각 경로가 홈에서 바로 열림.

### 부정
1. **SEO 모멘텀 리셋 위험** — 현재 `/`가 "HebronGuide 시애틀 한인 가이드" 등 키워드로 구글 축적된 콘텐츠. H1·메타·구조 변경은 랭킹 변동 가능.
2. **기능 밀도 감소** — 현재 홈은 76 도시 리스트·광고 CTA·파트너 교회 등을 조밀하게 노출. home-light는 핵심 4 입구만.
3. **방문자 기대 변화** — 재방문자에게는 익숙한 홈의 "그 자리"가 사라짐.
4. **SPA React 앱과 분리 문제** — 현재 `/`는 React SPA 랜딩. home-light는 정적 HTML. 승격 시 vercel.json 라우팅 재검토 필요.

## 세 가지 승격 시나리오

### A안 (급진 교체)
`/home-light` → `/`. 기존 `/` 콘텐츠는 `/index-classic.html`로 백업.
- 장점: 즉시 정체성 반영.
- 단점: SEO 리셋 위험 가장 큼.

### B안 (점진 교체 · 추천) ★
2주간 `/light-home` 유지 + 메인 `/`에서 "환대의 분광 보기" 1차 CTA로 유도. 2주 뒤 유입·체류 데이터 비교 후 결정.
- 장점: 데이터 기반 결정, SEO 안전.
- 단점: 결정 2주 지연.

### C안 (현상 유지)
`/`는 그대로. home-light는 Phase 2 디자인 쇼케이스로 유지하되 승격 안 함.
- 장점: 안정성 최대.
- 단점: 정체성 전달 반감.
