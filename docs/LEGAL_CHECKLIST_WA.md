# 법적으로 어디에 물어볼 것인가 — 워싱턴주 · 시애틀 · 킹카운티

**조사: 2026-09-18**

> **이 문서는 법률 자문이 아니다.** 공개된 관청 자료를 직접 찾아 정리한 것이다.
> 실제 결정 전에 변호사 검토를 받아야 한다. 아래 6번에 어디서 받는지 적었다.

대상: [HOSPITALITY_TABLE_AND_STAY.md](HOSPITALITY_TABLE_AND_STAY.md) — 개인 가정의 식탁과 잠자리

---

## 먼저 — 내가 세웠던 순서가 틀렸다

처음에 이렇게 말씀드렸다.

```
틀림    무료 식탁  →  유료 식탁  →  하룻밤  →  연장
```

조사해 보니 **법적으로는 반대에 가깝다.**

```
맞음    무료 식탁                    허가 필요 없음
        숙박 + 아침만 (방 2개 이하)   면제 경로가 있다
        유료 저녁 식탁                가장 애매하다
```

**"저렴한 값에 저녁 한 끼를 판다"가 가장 어려운 항목이었다.** 아래 2번에 이유를 적는다.

## 1. 숙박 — 시애틀 단기 숙박 사업자 면허

**자기 집 방 한 칸을 빌려줘도 면허가 필요하다.**

| | |
|---|---|
| 필요한 것 | **두 가지** — 사업자 세금 증명(business license tax certificate) **+** 단기 숙박 규제 면허 |
| 자기 집 방 | 부엌·욕실이 따로 없는 방은 **추가 면허 없이** 본인 거주지 면허 하나로 덮인다. 방 3개를 내놔도 면허는 하나 |
| 비용 | **$75 / 연 1회 갱신** |
| **요구 조건** | **단기 숙박을 커버하는 책임보험 증명** · 손님용 현지 연락처 · 건축·안전 코드 준수 서명 · 실내에 안전 정보 게시 |

### 여기에 전화하면 된다

```
시애틀시 규제서비스 (FAS)
  전화   (206) 386-1267
  이메일 STR@seattle.gov
```

> **보험이 조건에 들어 있다는 점을 보십시오.** 일반 주택 보험은 영업을 커버하지 않는다.
> 면허를 받으려면 **따로 보험을 들어야 한다**는 뜻이다. 이건 추측이 아니라 신청 요건이다.

## 2. 음식 — 집에서 만든 끼니를 돈 받고 주는 것

### 확인된 것: 워싱턴주 Cottage Food 허가로는 안 된다

| | |
|---|---|
| 근거 | RCW 69.22.030 |
| 허용 범위 | **상온 보관되는 저위험 식품만** — 빵·과자, 표준 잼·젤리, 식초, 건조 믹스 |
| **조리한 끼니** | **해당되지 않는다** |
| 비용 | $355 / 2년 · WSDA 검사관이 **집 주방을 검사** |
| 한도 | 연 매출 $35,000 · 직거래만 (온라인·도매·주외 판매 금지) |
| 라벨 의무 | "Made in a Home Kitchen that has not been subject to standard inspection criteria" 문구 그대로 |

**전통 음식으로 저녁 한 끼를 대접하고 값을 받는 것은 이 허가로 안 된다.**

### 그런데 — 숙박에는 면제 경로가 있다 (킹카운티)

**이것이 오늘 찾은 것 중 가장 중요하다.** 조건을 다 갖추면 식품 허가가 면제된다.

| 조건 | 목사님 모델과 |
|---|---|
| **집주인이 그 집에 거주할 것** (owner occupied) | **"그 집 안에 사람이 있다" — 정확히 일치한다** |
| 손님 침실 **2개 이하** | 작은 집이 오히려 맞는다 |
| **아침식사만** 제공 | 저녁은 안 된다 |
| 광고·브로슈어·등록처 게시물에 **"규제·검사받지 않은 주방에서 조리됨"**을 알릴 것 | 우리 안내문에 그대로 넣으면 된다 |

**면제라도 「Exempt from Permit」 신청서를 내고 보건국 승인을 받아야 한다.** 그냥 넘어가는 게 아니다.

조건을 하나라도 못 맞추면(저녁을 주거나, 방이 3개거나) **정식 식품업 허가**가 필요해진다.

```
킹카운티 공중보건 — 식품업 허가
  kingcounty.gov  →  Food business permits  →  Permit exemptions
```

## 3. 30박 선 — 법 조항을 찾았다

**RCW 59.18.620**

> 호텔·모텔 **또는 그 밖의 단기 숙박 장소**에서, **소유자가 알고 동의한 상태로 30일 연속** 머문 사람은
> 이 조항의 목적상 **세입자로 본다.**

그리고 두 가지가 더 있다. **이게 제 계획을 고쳐야 하는 이유다.**

- **이 조항의 적용을 피하려는 목적의 중단은 인정되지 않는다**
- **이 조항을 포기하는 약정은, 구두든 서면이든, 공서양속 위반으로 무효다**

### 그래서 「29박 자동 종료」를 이렇게 고친다

```
틀림   29박 → 하루 비우고 → 다시 29박      ← 법이 이미 막아 놓았다
맞음   29박 → 진짜로 끝난다. 이어가려면 다른 관계로 다시 시작한다
```

자동 종료는 **법을 피하는 장치가 아니라 진짜 종료**여야 한다. 그리고 약관에
"세입자가 아님에 동의한다"는 문구를 넣어도 **효력이 없다.**

> 참고 — 30일 규정은 **단기 숙박 시설**에 대한 것이다.
> 일반적으로 손님이 며칠 만에 자동으로 세입자가 되는 주 전체 규칙은 없다.
> 다만 세입자 여부는 **당사자들의 실제 행동으로도 성립**한다(RCW 59.18.030).
> 그래서 이것이야말로 변호사에게 물어야 할 항목이다.

## 4. 사업자 등록

시애틀 단기 숙박 면허의 **전제 조건**이다. 면허만 따로 받을 수 없다.

```
워싱턴주 사업면허 서비스 (Business Licensing Service) — 주 세무국(Dept of Revenue)
```

호스트 개인이 받아야 하는지, 헤브론이 받는지가 갈린다. **이것도 변호사에게 물을 항목이다.**

---

## 5. 배경조사를 시작할 때 — 연방법

개인 배경조사를 받아 그 결과로 사람을 거절하면 **FCRA**(연방 공정신용보고법) 의무가 생긴다.
안내는 **연방거래위원회(FTC)** 가 사업자용으로 공개하고 있다.

시작하기 전에 읽는다. 시작한 뒤에는 늦다.

## 7. 변호사에게 가져갈 질문 — 이대로 물으면 된다

한 시간 상담이면 충분하다. 이 일곱 가지를 적어 가시면 된다.

1. **헤브론이 소개만 하고 돈을 만지지 않으면**, 우리가 숙박업자가 되는가?
2. 호스트 개인이 시애틀 단기 숙박 면허와 사업자 등록을 각자 받아야 하는가, 헤브론이 묶어서 할 수 있는가?
3. **무료로 저녁 한 끼를 대접하는 것**은 식품 허가가 필요 없다고 봐도 되는가? 재료비를 나누면 달라지는가?
4. RCW 59.18.620의 30일 — **우리 같은 가정 환대에도 적용되는가?** 29박 종료가 실제로 보호가 되는가?
5. 약관에 무엇을 쓰면 **면책이 살아 있고**, 무엇을 쓰면 오히려 책임이 생기는가?
6. **"○○교회의 추천을 받았습니다"** 라고 쓰는 것은 안전한가? 어디까지가 검증 주장인가?
7. 사고가 났을 때 **호스트의 주택 보험**과 헤브론의 노출은 각각 어떻게 되는가?

## 8. 오늘 당장 할 수 있는 것과 없는 것

| | 지금 | 근거 |
|---|---|---|
| **무료 식탁** (교회 목장) | **가능** | 이미 하고 있다. 돈이 오가지 않는다 |
| **무료 식탁** (개인 가정) | **가능** | 같다. 호스트만 넓히면 된다 |
| 유료 저녁 식탁 | **하지 않는다** | Cottage Food 허가로 안 되고, B&B 면제는 아침만이다 |
| 숙박 | **면허·보험·보건국 승인 뒤에** | 1번 · 2번 |
| 며칠 연장 | **변호사 검토 뒤에** | 3번 |

**무료 식탁부터 시작한다.** 이건 오늘 열 수 있다.
