## 그의 핵심 주장 넷

### ① 진실의 이동

인간이 판단의 무대에서 내려오고, **AI가 선택한 정보만 살아남습니다.**
사람들은 AI가 요약해준 문맥을 곧 진실로 받아들입니다.

> HebronGuide에 옮기면 —
> **"어느 도시에 한인 교회가 있나"** 를 이제 사람들은 우리에게 묻지 않고 AI에게 묻습니다.
> 그 답에 우리가 없으면, 959개 교회를 모아둔 일이 없던 일이 됩니다.

### ② 컨텍스트는 보이지 않는 중력

AI가 세상을 보는 **확률적 지도**입니다. 낱말이 아니라 관계가 답을 만듭니다.

### ③ 엔티티 매핑 — GEO의 시작

> **"AI에게 우리 브랜드를 모호한 키워드가 아닌 측정 가능한 사물로 등기하는 것."**

**'등기'** 라는 말이 정확합니다. 부동산 등기처럼 — 이름·위치·소유·경계가 확정되어야 존재로 인정됩니다.

### ④ GEO는 디지털 복지 인프라다 ★

그는 GEO를 마케팅 기법을 넘어 **시민의 정보 접근권**으로 봅니다.
공공 데이터를 AI 친화적 엔티티 구조로 재설계해, **국민이 AI를 통해 정확한 행정 서비스에 닿게** 해야 한다고 말합니다.

> ### 이 대목이 HebronGuide의 자리입니다.
>
> 새로 온 이민자에게 **정착 정보 접근권**은 복지입니다.
> 영어가 서툰 사람이 AI에게 물었을 때 정확한 한인 교회·정착 정보에 닿는 것 —
> 그것이 우리가 하는 일의 정확한 정의입니다.
>
> **마케팅으로 하면 광고가 되고, 복지로 하면 사명이 됩니다.**
> 우리는 후자입니다. [`CORE_VISION.md`](CORE_VISION.md) 섬김의 원칙과 같은 자리입니다.

## 엔티티 등기 — 우리 실측 상태

2026-08-11 배포본 실측:

| 항목 | 상태 | 판정 |
|---|---|---|
| `llms.txt` 엔티티 정의 | 6,646자, 정의 문단 있음 | **등기됨** |
| 도시 페이지 JSON-LD | 9종 8,978자 (Organization·City·FAQPage·ItemList…) | **등기됨** |
| hreflang | ko · en · es · x-default 선언 | 선언만 |
| **도시 페이지 본문(HTML)** | **68자** — React라 비어 있음 | **미등기** |
| **교회 959개 실제 목록** | ItemList 항목 **5개**뿐 | **미등기** |
| **영어 설명 문장** | `llms.txt` **0개** | **미등기** |
| `inLanguage` 선언 | 없음 | 미등기 |

### 즉 — 이름은 등기됐는데 재산이 등기가 안 됐습니다

```
등기부에 "HebronGuide" 라는 이름은 올라가 있다.
그런데 "무엇을 가졌는가"(교회 959개)가 비어 있다.

AI는 우리가 존재하는 건 알지만, 무엇을 줄 수 있는지는 모른다.
```

## 그런데 지금 바로 등기하면 안 됩니다

**우리 재산 장부가 틀려 있기 때문입니다.**

| | |
|---|---|
| 교회 959개 중 **460개**가 도시가 틀려 어느 페이지에도 안 뜸 | 오늘 확인 |
| **완전한 주소**(도시·주·우편번호)는 **87개(9%)** | 오늘 확인 |
| `verified_at` — 누가 언제 확인했는지 기록 | **없음** |

> **틀린 데이터를 구조화하면 AI가 틀린 답을 확신 있게 말합니다.**
> 사람은 목록을 보고 "이상하네" 하지만, **AI는 그대로 인용하고 퍼뜨립니다.**
> 이재홍의 표현을 빌리면 — 잘못된 컨텍스트를 등기하는 것입니다.

```
① llms.txt를 사실에 맞춘다                    ← 2026-08-11 완료

④ 교회 목록을 JSON-LD ItemList에 등기한다       ← 그때 AI가 정확히 답한다
⑤ 영어 엔티티를 세운다                          ← 아래
```

**②③ 없이 ④를 하면 틀린 정보를 증폭시킵니다.**

## 영어 등기 — 지금 비어 있는 것

목사님 요청: *"한글과 영어로 자유자재로 나오게."*

영어권 AI 질의에 답하려면 **인용할 영어 문장**이 있어야 합니다. 지금은 없습니다.

| 필요한 것 | 지금 |
|---|---|
| `llms.txt` 영어 섹션 | **0문장** |
| JSON-LD `description` 영어 | 이름만 있고 설명 없음 |
| `inLanguage` 선언 | 없음 |
| 영어 페이지 실체 | `?lang=en` — 쿼리 파라미터라 AI는 같은 빈 HTML을 받음 |

### 이름 세트 고정 (엔티티 일관성)

AI가 `HebronGuide` 와 `헤브론가이드` 를 다른 것으로 볼 수 있습니다.

```
항상 함께 쓴다:
  HebronGuide (헤브론가이드, hebronguide.com)
  HebronGuide Seattle (시애틀 헤브론가이드)

절대 쓰지 않는다:
  우리 플랫폼 · 저희 서비스 · 본 사이트 · 헤브론(단독)
```
