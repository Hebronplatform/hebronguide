## 3 · 공유 메시지 작성 원칙

### DO
- "**참고 되실만한**" / "**혹시 쓸모 있으시면**" 등 겸손한 톤
- 광고 아님 **명시**
- 그룹/카페 룰 **존중** ("어긋나면 삭제하겠습니다")
- 짧게 (3-5줄)
- 링크 1-2개까지

### DON'T
- 과장 ("최고의"·"유일한") → 반감
- 긴 설명 → 스크롤 넘김
- 같은 그룹에 **같은 자료 반복** 공유 → 스팸 신호
- 그룹 운영자 승인 없이 **광고 신청 URL** 공유 → 상업적 반감
- 다른 커뮤니티 비하 → 금물

## 4 · 그룹별 전용 랜딩 활용 (`/from.html`)

**URL 패턴**:
```
hebronguide.com/from.html?c=<커뮤니티명>&utm_source=<소스>
```

**예시**:
```
hebronguide.com/from.html?c=미국%20사는%20한국인&utm_source=facebook
hebronguide.com/from.html?c=시애틀%20한인회&utm_source=naver-cafe
hebronguide.com/from.html?c=호주나라&utm_source=kakao-chat
hebronguide.com/from.html?c=토론토%20유학생&utm_source=telegram
```

**효과**:
- 사용자가 "**[커뮤니티명]에서 오신 분**" 환영 받음 → 소속감
- UTM으로 **어느 커뮤니티에서 왔는지 추적**
- 추천 콘텐츠 4개로 간결 유도
- 광고 CTA 노출 (수익)

**공유 예시**:
```
안녕하세요, [그룹명] 멤버분들께 Hebron 소개드립니다.
→ hebronguide.com/from.html?c=[그룹명 URL인코딩]&utm_source=[플랫폼]
```

## 6 · UTM 추적 세팅

### 기본 UTM 구조
```
?utm_source=<커뮤니티명>&utm_medium=<플랫폼>&utm_campaign=<목적>
```

### 예시
- 미국 사는 한국인 Facebook: `?utm_source=misakhan&utm_medium=facebook&utm_campaign=settlement-faq`
- 시애틀 KakaoTalk: `?utm_source=seattle-kakao&utm_medium=kakao&utm_campaign=seattle-plus`
- 뉴욕 한인회 뉴스레터: `?utm_source=kwanyc&utm_medium=email&utm_campaign=newsletter-oct`

### 추적 방법 (지금 가능)
- `/from.html` JavaScript가 `localStorage.hg_referrer`에 소스 저장
- Vercel Analytics (설치되어 있다면) 자동 집계
- Google Search Console (설치되어 있다면) 유입 소스 분석

### 추적 방법 (후속 설치 가능)
- Vercel Analytics 활성화 — 1클릭
- Plausible / Umami (오픈소스·개인정보 보호형)
- Google Analytics 4

## 7 · 바이럴 전략 — "환대의 분광 챌린지"

**아이디어**: 사용자가 자기 도시의 환대 사진·일화를 **"환대의 색"**과 함께 공유.

**방법**:
1. Instagram/Facebook/Threads 포스트
2. 해시태그: `#환대의분광` `#HebronGuide` `#환대의색`
3. 사진 1장 + 짧은 문장 (예: "**이 도시의 환대는 에메랄드 — 시애틀**")
4. 운영자(Hebron)가 리그램·소개 → 피드백

**보상**:
- 바이럴 참가자 중 추첨 → **Hebron Weekly 뉴스레터 소개**
- `/voices.html` 섹션에 사례 등재
- 대표님 직접 감사 메시지

**첫 발화**: 대표님이 시애틀 환대 사진 1장을 "에메랄드" 색과 함께 공유 → 시작
