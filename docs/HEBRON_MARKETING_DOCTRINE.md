# Hebron 마케팅 정본 — 모든 사업에 적용

**정립: 2026-08-11 | 폴 김 목사 지시**

> **적용 범위 — Hebron Platform LLC가 만드는 모든 것**
> HebronGuide · NanuriWeb · Kchurch911 · **시애틀지구촌교회** · 앞으로 만들 모든 사업
>
> 근거: 김팀장 × 이재용 대표 AEO 라이브 강연 전체,
> 이재홍 『AI의 선택을 부르는 AEO·GEO 생존전략』(미래의창, 2026)

---

## 0. 두 손을 다 쓴다 — 이것이 가장 위에 있다

> **"변하는 것과 변하지 않는 것이 있다. 둘 중 어느 하나에 치중되면 안 되고**
> **둘 다 양손잡이가 되어야 한다."**

| ❌ 한쪽만 | |
|---|---|
| 트렌드에만 매몰 | AEO 쫓아다니다 본질을 잃는다 |
| 본질만 하며 문 닫음 | 좋은 것을 아무도 못 찾는다 |

```
변하지 않는 것 → 사람이 오는 길목(퍼널)을 만드는 것. 차가운 마음을 따뜻하게.
변하는 것      → 그 길목의 입구가 어디인지. 네이버 → 구글 → AI
```

**입구가 바뀌었을 뿐, 길을 만드는 일은 그대로입니다.**

---

## 1. 바뀐 것은 "첫 입구" 하나다 — 정확히 말하기

전부가 바뀐 게 아닙니다. **딱 한 지점**입니다.

> **"AEO는 마케팅의 모든 것을 바꾸는 게 아니라,**
> **사람이 필요를 느꼈을 때 처음 찾아 나가는 그 첫 퍼널이**
> **검색엔진에서 답변엔진으로 바뀐 것이다."**

**그리고 그 한 지점이 치명적인 이유:**

> **1단계에서 추천되지 않으면, 그다음부터 여정에 진입 자체를 못 합니다.**

---

## 2. 이미 마음이 있는 사람을 만난다

| | 광고·알고리즘 노출 | 검색·AI 질의 |
|---|---|---|
| 대상 | **없던 필요를 만들어야** 함 | **이미 절실한 사람** |
| 그래서 | 자극적일 수밖에 없다 | 담담해도 된다 |
| 비용 | 끄면 끝 | 쌓인다 |

> **"광고는 끄면 끝이고 AI 학습에 아무 도움이 안 됩니다.**
> **콘텐츠는 쌓이고, 쌓인 것이 학습되고, 그건 영원히 갑니다."**

**Hebron의 모든 사업은 후자만 합니다.** 자극으로 없던 필요를 만드는 일은 하지 않습니다.
→ [`WORDS_OPEN_DOORS.md`](WORDS_OPEN_DOORS.md) 원칙 2 (조급하게 만들지 않는다)

---

## 3. AI가 추천하려면 세 가지가 필요하다 ★

```
① 인지 —  나를 아는가              (엔티티가 등기되어 있는가)
② 적합 —  이 맥락에 맞는다고 보는가  (뾰족한 근거가 있는가)
③ 최신 —  지금도 유효하다고 보는가   (갱신되고 있는가)
```

**셋 중 하나만 없어도 추천은 없습니다.**

### Hebron 자가진단 — 분기마다

**로그인하지 않은 창(시크릿·프라이빗)에서** 물어야 합니다.
내 계정은 대화 기록이 있어 나를 편들어 줍니다. 그건 진짜 답이 아닙니다.

```
□ "○○" 이 뭐야?                    → ① 인지
□ [우리가 노리는 질문] 추천해줘      → ② 적합
□ 답에 나온 정보가 지금 맞나?        → ③ 최신
```

---

## 4. 뾰족함의 법칙 — 넓은 말로는 절대 못 이긴다

### 이기는 길은 둘뿐이다

```
① 압도적인 양   → 돈이 든다. 우리는 못 한다.
② 뾰족한 근거   → 이것뿐이다.
```

### 예시가 전부를 설명한다

| ❌ 넓은 말 | ✅ 뾰족한 근거 |
|---|---|
| 배송이 빠른 회사 | **서울 전역 1시간 이내** |
| 친절한 치과 | 네이버 리뷰 5.0 · 라미네이트 |
| 웨딩 관리샵 | **"웨딩드레스 입어봤는데 목이 짧아 보여요"** |

**"배송 빠른 회사"로는 쿠팡을 못 이깁니다. "1시간 이내"는 이깁니다.**

### 나이로비의 법칙 ★★

> **"뉴욕·서울은 데이터가 많아 경쟁이 세다.**
> **나이로비는 비어 있다. 거기에 카페 글 하나만 써도 그게 추천된다."**

**이것이 Hebron의 전부입니다.**

```
❌ 붐비는 자리  "시애틀 한인 교회"          → 이미 여럿 있다
✅ 비어 있는 자리 "시애틀 가정교회 목장"      → 아무도 없다
```

2026-08-11 실측 — AI가 직접 이렇게 답했습니다:

> *"'가정교회 목장'이라는 특정 명칭의 교회에 대한 구체적인 정보는 찾을 수 없었습니다."*

**우리가 다루는 모든 영역이 나이로비입니다.**
한인 이민자 · 가정교회 · 디아스포라 정착 — **한국어 데이터조차 얇은 곳들입니다.**
대기업이 절대 안 들어옵니다. 시장이 작아서요. **그래서 우리 자리입니다.**

## 5. 이름과 메시지를 하나로 고정한다

> **"AI가 뭐라고 말해줬으면 하는 그 명칭을 모든 곳에서 똑같이 써야 합니다."**

여러 곳에 다른 이름, 다른 메시지로 올리면 **AI가 다른 것으로 봅니다.**

### Hebron 공식 명칭 — 어디서나 이것만

```
HebronGuide (헤브론가이드, hebronguide.com)
시애틀지구촌교회 (Global Mission Church of Greater Seattle)
Mokjang (House Church, 목장)          ← 교회 공식 영문 표기
NanuriWeb (나누리웹, nanuriweb.com)
Kchurch911 (kchurch911.com)
Hebron Platform LLC                    ← 약관·법적 문서에만
```

**절대 쓰지 않습니다** — 우리 플랫폼 · 저희 서비스 · 본 사이트 · 헤브론(단독)

## 6. 사업별 적용

### HebronGuide

| | |
|---|---|
| **뾰족한 근거** | "이번 주 금요일 저녁에 앉을 식탁" — 아무도 안 한다 |
| **비어 있는 자리** | 시애틀 가정교회 목장 · 도착 첫 주의 외로움 |
| **쓰지 않을 말** | "믿을 만한 가게" (업소 3개) |
| **막는 것** | 460개 도시 오류 → 고치기 전엔 교회 목록 등기 금지 |

### 시애틀지구촌교회 ★ 교회도 같습니다

**교회에 "매출"은 없습니다. 그래도 이 구조는 그대로입니다.**

```
구매 의사   →   찾고 있는 마음
                (이사 왔다 · 힘들다 · 아이 때문에 · 외롭다)

첫 행동     →   검색. 이제는 AI에게.

전환        →   결제가 아니라 문 안에 들어오는 것
```

> **"교회도 하나님의 자녀가 될 사람들이 찾는 교회가 되어야 한다."**
> — 폴 김 목사, 2026-08-11

**AI 검색 최적화가 교회에는 전도의 길목입니다.**
그 사람이 하나님을 만나는 첫 입구에 우리가 있느냐 없느냐입니다.

| | |
|---|---|
| **뾰족한 근거** | 환대(Hospitality)·목장(Mokjang) — **공식 사명에 들어 있다** |
| **비어 있는 자리** | "시애틀 가정교회" · "린우드 한인교회" |
| **가장 급한 것** | **예배 시간.** 지금 홈페이지 어디에도 없다 |
| **AI 3조건** | 인지 ✓(주소·전화 교정) · 적합 ✗(목장 페이지 없음) · 최신 ✗(예배시간 없음) |

> **찾아냈는데 언제 가는지 모르면 못 옵니다.**
> 아무리 노출돼도 ③최신이 비면 추천되지 않습니다.

## 7. 하지 않을 것 ★ 강연에서 걸러낸 것

강연은 유익했지만 **파는 사람의 말**입니다. 그대로 따르지 않습니다.

| 강연에서 | 우리 판단 |
|---|---|
| **415개 제휴 사이트에 대량 배포** | **하지 않습니다.** 같은 강연이 네이버 블로그를 *"노이즈 심한 쓰레기"* 라 비판했는데, 대량 배포는 그것과 같은 일입니다. 검증 없는 확산은 우리 해자(신뢰)를 스스로 깎습니다 |
| "전환율 50%" · "매출 300%" | **영업 숫자.** 우리 숫자로 확인하기 전엔 인용하지 않습니다 |
| "지금이 골든타임, 빨리" | 조급함은 우리가 쓰지 않는 말입니다 → 원칙 2 |
| 콘텐츠 대량 생산 | **앉을 자리가 먼저입니다** → [`NICHE_STRATEGY.md`](NICHE_STRATEGY.md) |

> **"빈집을 털어라"는 표현을 우리는 쓰지 않습니다.**
> 우리는 비어 있는 자리에 **밥상을 차립니다.**

## 8. 순서 — 모든 사업 공통

```
① 우리가 답할 수 있는 질문을 적는다   (없는 건 안 쓴다)
② 그중 비어 있는 자리를 고른다        (나이로비를 찾는다)
③ 이름·메시지를 하나로 고정한다
④ 사실을 정확히 등기한다              (틀린 등기는 안 하느니만 못하다)
⑤ 로그인 안 한 창에서 확인한다
⑥ 분기마다 다시 잰다                  (③최신)
```
