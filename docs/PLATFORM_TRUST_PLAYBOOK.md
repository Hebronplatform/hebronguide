# 낯선 사람을 집에 들이는 법 — 에어비앤비·카우치서핑에서 배운다

**정립: 2026-08-11**

> Yelp · 당근 · TripAdvisor는 [`MARKETING_STRATEGY.md`](MARKETING_STRATEGY.md)와
> [`DINING_GUIDE.md`](DINING_GUIDE.md)에 이미 있습니다.
> 이 문서는 **아직 다루지 않은 셋** — 에어비앤비 · 카우치서핑 · Nextdoor를 다룹니다.

---

## 왜 하필 이 셋인가

우리가 지금 시작한 일이 **목장 모임**입니다.
**낯선 사람을 개인의 집으로 부르는 일.**

이건 검색도 아니고 디렉토리도 아닙니다. 세상에서 이 문제를 정면으로 푼 회사가 둘 있습니다.

| | 무엇을 풀었나 | 결과 |
|---|---|---|
| **에어비앤비** | 낯선 사람의 집에서 자게 만들기 | 성공 — 신뢰를 설계로 풀었다 |
| **카우치서핑** | 낯선 사람 집에서 **공짜로** 자기 | **실패** — 우리와 가장 닮았고, 그래서 가장 무섭다 |
| **Nextdoor** | 이웃임을 증명하기 | 부분 성공 — 검증의 마찰을 보여준다 |

## 1. 에어비앤비 — 신뢰는 감정이 아니라 구조다

에어비앤비 이전에 모두가 말했습니다. *"낯선 사람 집에서 누가 자겠나."*
그들은 설득하지 않았습니다. **구조를 만들었습니다.**

### 일곱 가지 장치와 목장 적용

| 에어비앤비 | 왜 | 목장 모임 적용 |
|---|---|---|
| **양방향 후기, 동시 공개** | 둘 다 쓴 뒤 동시에 열어 보복을 막는다 | 다녀온 사람 한 줄 · 목자도 한 줄. **동시 공개** |
| **신원 확인** | 실명·신분증 | 목자는 교회가 보증한다 (이미 있음) |
| **프로필 사진 + 자기소개 의무** | 얼굴이 있으면 함부로 못 한다 | **목자 소개 한 줄** — 시트에 이미 넣기로 함 |
| **플랫폼 밖 거래 금지** | 밖으로 나가면 보호가 끊긴다 | 개인 연락처 대신 **카카오 채널 하나로** (적용됨) |
| **호스트 지급 보류** | 체크인 뒤 지급 — 사고 시 되돌릴 수 있게 | 우리는 돈이 안 오간다. 대신 **첫 방문 후 확인 연락** |
| **Superhost** | 성과로 얻는 지위, **돈으로 못 산다** | 「이 목록은 돈으로 살 수 없습니다」와 같은 사상 |
| **24시간 안전 지원** | 사고 시 즉시 연결 | **비상 연락 한 곳** — 지금 없다 |

### 마케팅에서 배울 하나 — Do things that don't scale

초창기 에어비앤비 창업자들은 뉴욕 호스트 집을 **직접 돌며 사진을 찍어줬습니다.**
확장 불가능한 짓이었지만, 예약이 눈에 띄게 늘었습니다.

> **목사님이 세 교회를 직접 찾아가기로 하신 것이 정확히 이것입니다.**
> 80개 도시를 자동화하는 것보다, 세 곳을 손으로 만지는 것이 먼저입니다.

## 2. 카우치서핑 — 우리가 죽을 수 있는 방식

**무료 환대 커뮤니티.** 돈을 받지 않고 낯선 여행자를 재워줍니다.
HebronGuide와 **철학이 거의 같았습니다.** 그런데 무너졌습니다.

### 무엇이 죽였나

**① 예고 없는 유료화**
오랫동안 무료였다가 2020년 갑자기 로그인 앞에 결제벽을 세웠습니다.
사용자들은 배신감을 느꼈고, 커뮤니티가 흩어졌습니다.
**돈이 문제가 아니라 약속이 깨진 것이 문제였습니다.**

**② 안전 사고 관리 실패**
특히 여성 게스트의 피해 사례가 쌓였는데 대응이 느렸습니다.
**환대 커뮤니티는 사고 하나로 전체 신뢰를 잃습니다.**

### 🚨 우리에게 직접 오는 경고

목사님이 이렇게 말씀하셨습니다 (2026-08-08):

> *"나중에는 광고가 들어가야 수입이 생겨서 이것을 계속 만들지."*

**맞는 말씀입니다. 그리고 정확히 카우치서핑이 죽은 자리입니다.**

수익화 자체가 문제가 아닙니다. **어떻게 하느냐**가 갈랐습니다.

```
❌ 카우치서핑 방식
   무료 → 어느 날 갑자기 결제벽 → 배신감 → 붕괴

✅ 지킬 방식
   ① 이미 한 약속은 깨지 않는다
      "찾는 것도 등록도 무료" — 이건 영구히 무료
   ② 광고는 새로 더하는 것이지, 있던 것을 뺏는 게 아니다
   ③ 광고와 순위를 절대 섞지 않는다  ← Yelp가 잃은 것
   ④ 미리 알린다. 기습하지 않는다
```

> **광고를 넣는 날, 목록의 순서가 1mm라도 바뀌면 우리는 카우치서핑이 됩니다.**

## 3. Nextdoor — 검증의 마찰

Nextdoor는 **우편으로 코드를 보내** 실제 그 동네에 사는지 확인했습니다.
가장 강한 검증이지만 가장 번거롭습니다.

**교훈** — 검증의 세기와 가입의 쉬움은 반비례합니다.
그래서 우리는 이렇게 나눕니다:

```
찾아보는 사람   → 검증 0. 가입도 없다. 문턱 없음
맞이하는 사람   → 검증 강하게. 교회·업소는 사람이 승인한다
```

**희소한 쪽(새로 온 사람)에게는 문턱을 두지 않고,
책임지는 쪽(맞이하는 사람)에게 문턱을 둡니다.**

## 예상 시나리오와 예방

일어날 법한 순서로 적습니다. 확률이 높고 피해가 큰 것부터.

### S1. 목장 모임에서 사고가 난다 ★ 가장 무섭다

**시나리오** — 처음 온 사람이 목자 집에 갔다가 불쾌한 일을 겪는다.
카우치서핑을 죽인 것이 이것입니다.

| 예방 | |
|---|---|
| 사전 | 목자는 교회가 보증한 사람만. 시트 편집 권한은 목사님만 |
| 당일 | 첫 방문은 **여러 명이 있는 자리**로 안내 |
| 사후 | **첫 방문 후 확인 연락** — "어떠셨어요?" 한 통 |
| 사고 시 | 즉시 그 목장을 화면에서 내린다. 조사 후 판단 |

**지금 비어 있는 것** — 사후 확인 연락, 비상 연락처.

### S2. 가짜 업소가 등재되어 사기가 난다

**시나리오** — *"HebronGuide에 있는 업소인데요"* 로 신뢰를 빌려 씀.

**예방** — [`FRAUD_DEFENSE.md`](FRAUD_DEFENSE.md) 3겹. 위험 신호 자동 감지 적용됨.
**비어 있는 것** — 피해 신고 창구.

### S3. 이단이 교회로 위장한다

**예방** — CULT_KEYWORDS + AI 게이트 (적용됨). 신천지 3,400+ 위장 단체 대응.
**주의** — 위장 단체는 이름을 바꿉니다. 키워드는 늙습니다. **분기별 갱신 필요.**

### S4. 광고를 넣자 커뮤니티가 등을 돌린다

**예방** — 위 9·10·11번. 특히 **순위를 건드리지 않는 것**.

### S5. 목사님 한 분에게 모든 것이 달려 있다

**시나리오** — 목사님이 아프시거나 바쁘시면 승인이 멈추고, 신청은 쌓이고,
사람들은 답이 없다고 느낍니다. **오늘 15일간 저장이 멈춘 것과 같은 종류입니다.**

| 예방 | |
|---|---|
| 자동 | 조용한 실패를 막는다 (오늘 적용) |
| 위임 | 세 교회 중 한 분에게 승인 권한 나누기 |
| 알림 | 신청이 3일 넘게 대기하면 알림 |

### S6. 가짜 후기·자화자찬이 생긴다

**예방** — 후기를 만들 때 **처음부터** 양방향·동시 공개로. 나중에 고치면 늦습니다.
Yelp·TripAdvisor가 가짜 후기로 잃은 신뢰를 되찾지 못했습니다.

### S7. 한인회·교단 정치에 휘말린다

**예방** — 이미 원칙 있음. [`KOREAN_ASSOCIATION_NETWORK.md`](KOREAN_ASSOCIATION_NETWORK.md)
한인회는 얇은 연결만. 앵커는 교회.
