## ① 30~90일 정착 로드맵 — 완료·배포됨

체크리스트가 **Day 1 짜리 8개**뿐이었습니다. **16개 3단계**로 늘렸습니다.

| 단계 | 항목 |
|---|---|
| 도착 첫 주 | SIM · 은행 · 거주지 · 면허 전환 · SSN · 건강보험 · 학교/어학원 · 주치의 |
| **2~4주차** | **신용(credit) 쌓기** · 장기 렌트 계약 · 전기·인터넷 · 자동차와 보험 |
| **2~3개월째** | 운전면허 실기 · 자녀 학교 서류 · 세금 신고 준비 · **앉을 자리 찾기** |

**핵심은 credit 입니다.** SSN 받은 즉시 시작해 6개월이 걸리는데, 늦게 시작하면
집도 차도 계속 막힙니다. 전기 보증금·렌트 보증금·자동차 보험료가 전부 여기 걸립니다.
**아무도 이걸 먼저 말해주지 않습니다.**

마지막 항목이 **「앉을 자리 찾기」**입니다 — 석 달쯤에 외로움이 옵니다.
서류가 아니라 사람입니다. 여기가 우리 자리입니다.

```
새 테이블 0 · 새 API 0 · 로그인 불필요 · 82개 도시 즉시 적용
```

언어 토글도 **EN · KO** 순서로 바꿨습니다(표시 순서만, 기본 언어는 그대로).

## ② 정부지원 한국어 매핑 — 완료·배포됨

**hebronguide.com/seattle-aid.html**

### 브리프가 전제한 것이 틀렸습니다. 그 정정이 이 페이지의 핵심입니다.

> **CFDA 19.510 · 93.566 은 개인이 신청하는 지원금이 아닙니다.**
> 연방정부가 주정부·재정착기관에 주는 **교부금 번호**입니다.
> 대상도 난민·망명자·쿠바/아이티 입국자·인신매매 피해자·SIV·무동반 난민 아동이라
> **취업·가족·유학 비자로 온 한인 다수는 해당되지 않습니다.**

**WA MASS 도 마찬가지입니다.** "2022-01-01 이후 첫 입국"만 보고 기대하기 쉬운데
**"추방 절차(removal proceedings) 중"** 이라는 조건이 붙어 있습니다.

그래서 페이지 첫 화면이 **「신분에 따라 갈립니다」** 입니다.
**헛걸음을 막는 것이 목록을 늘리는 것보다 낫습니다.**

### 실은 것 (전부 출처·확인일 명시)

| | 눈여겨볼 점 |
|---|---|
| 연방 난민 지원 | 현금·의료 8개월 · 사회서비스 5년. 기관을 통한다 |
| **주거 안정 지원** | **난민 신분을 요구하지 않는다. "미국 거주 5년 이하"가 핵심** |
| WA MASS | 추방 절차 중이어야 함 — 일반 이민자 해당 안 됨 |
| FAP E&T | 식품지원 수급자 대상 취업·훈련 |
| Medicaid | **2026-10-01 부터 비시민 성인 자격 변경** |

### 싣지 않은 것

학교 무상등록·급식 · WIC · 응급의료 · 도서관 ESL —
**확인하지 못해서입니다.** 페이지에 그 사실을 밝혀 두었습니다.
없는 것을 있다고 적으면 헛걸음을 시킵니다.

## ③ 015 RLS — 목사님 손이 필요합니다 (5분)

**제가 못 합니다.** PostgREST 로는 DDL 이 실행되지 않습니다.

```
hebronguide.com/sql-guide.html   ← 초등학생도 따라 하도록 만들어 둔 안내 (라이브 200 확인)
docs/migrations/015_community_items_rls.sql
```

`community_items` 에 신청자 **이메일·전화**가 들어 있는데
RLS 가 꺼져 있으면 **미승인 신청까지 누구나 읽을 수 있습니다.**
3주 밀렸습니다. 다른 무엇보다 이것이 먼저입니다.
